#It Asset Management System
#Project Overview

This project models an It Asset and Help Desk Management System of a fictional company named "cat" with 500 employees.
The system will track company hardware, software licenses, employee asset assignments, maintenance history, and help desk tickets.

#Company Goals

- Track laptops, desktops, monitors, printers, phones, and network equipment
- Record which assets are assigned to employees
- Maintain asset assignment and repair history
- Track software licenses and expiration dates
- Manage employee help desk tickets
- Assign tickets to IT technicians
- Measure help desk and technician performance
- Produce reports about assets, warranties, licenses, and tickets

#Comapny Departments

- Human Resources
- Finance
- Information Technology
- Marketing
- Sales
- Operations
- Executive

#Planned Data

The finished database will include approximately:

- 500 employees
- 2,500 IT assets
- 3,000 help desk tickets
- 200 software licenses
- 20 departments

#Project Phases

1. Requirements gathering and database design
2. PostgreSQL schema implementation
3. Realistic sample-data generation
4. Reporting and analytical SQL queries
5. Power BI and Python integration
